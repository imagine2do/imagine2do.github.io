개인정보처리방침

앱: Cueluma · 운영자 및 개인정보 문의 담당: Hipdo
시행일: 2026년 10월 18일 · 문의: imagine2do@naver.com

Cueluma는 생활 소리와 한국어 대화를 기기 안에서 처리합니다. 원본 마이크 음성과 실제 대화를 파일이나 개발자 서버에 저장하지 않습니다. 회원가입·광고·결제·추적 SDK는 없습니다.

1. 마이크와 음성 인식

사용자가 생활 소리 감지 또는 대화 자막을 직접 시작한 동안 마이크를 사용합니다. 생활 소리 분류와 지원되는 한국어 음성 인식은 온디바이스로 처리합니다. 원본 마이크 음성과 실제 대화 내용을 파일이나 자체 서버로 저장·업로드하지 않습니다. 기기가 온디바이스 한국어 인식을 지원하지 않으면 서버 인식으로 자동 전환하지 않습니다.

마이크 권한은 소리 입력, iOS 음성 인식 권한은 한국어 자막, 알림 권한은 소리 알림 표시에 사용합니다. 거부하면 해당 기능이 제한됩니다. iPhone의 잠금 중 듣기는 사용자가 직접 선택한 세션에서만 동작하며, Android 자막은 화면 잠금·앱 전환 때 중지합니다. 권한 철회나 오디오 중단 후 마이크를 자동으로 다시 시작하지 않습니다.

2. 기기에 보관하는 정보

생활 소리 기록에는 소리 유형·시각·모델 점수·확인 여부·피드백·전달 상태가 포함됩니다. 휴대폰의 기본 보관은 7일·최대 200건이며, 워치에는 최근 최대 20건을 보관합니다. 앱을 실행하거나 기록을 갱신할 때 만료분을 정리합니다. 보관을 끄거나 전체 삭제할 수 있습니다. 기기 내 진단에는 상태·횟수·지연·오류 코드가 들어가며 원본 음성과 실제 자막은 넣지 않습니다. 앱의 기록과 진단은 OS 백업 제외 대상으로 설정합니다.

감지 대상, 알림 간격, 자막 글씨 크기, 워치 전송 및 iPhone 잠금 중 듣기 선택은 기기에 저장됩니다. 잠금 중 듣기는 처음에는 꺼져 있습니다. 대화를 종료해도 설정은 유지하지만, 앱을 다시 열었다는 이유만으로 마이크가 시작되지는 않습니다.

자막과 입력한 답변은 메모리에서 사용하며 대화 종료 또는 해당 화면 이탈 시 지웁니다. 사용자가 화면을 캡처하거나 OS 키보드를 이용할 때의 데이터 처리는 해당 플랫폼·키보드의 설정과 정책을 따릅니다.

3. 워치 전송

워치 자막 전송을 직접 켠 경우 최근 최대 160자를 수명이 짧은 실시간 메시지로 보내며 5초 후 만료합니다. 실제 자막을 지속 동기화 큐에 저장하지 않습니다. 생활 소리 이벤트와 확인·삭제 상태도 연결된 워치와 동기화합니다.

Apple WatchConnectivity와 Google Wearable Data Layer가 전송을 처리하며 OS가 관리하는 네트워크 경로를 사용할 수 있습니다. 이는 개발자의 자체 서버로 보내는 기능이 아닙니다. Apple Watch 자체 마이크 인식은 원본 음성과 자막을 iPhone으로 보내지 않습니다. Wear OS 단독 음성 인식은 현재 제공하지 않습니다.

4. 모델 캐시와 선택한 테스트 파일

Apple Watch 단독 자막을 처음 시작할 때 앱에 포함된 압축 모델을 기기 내 비공개 캐시에 복원합니다. 약 81MB의 추가 공간을 사용합니다. 캐시에는 모델 파일만 포함되며 녹음이나 자막은 없고 OS 백업에서 제외됩니다. OS가 캐시를 정리하면 다음 실행 때 다시 준비할 수 있습니다.

사용자가 파일 선택기로 직접 가져온 WAV 테스트 파일은 메모리에서 분석하며 개발자에게 업로드하지 않습니다. 사용자가 ‘분석 결과 공유’를 누르면 원본 오디오가 아닌 결과 메타데이터가 사용자가 선택한 앱으로 전달됩니다. 선택한 외부 앱의 처리는 그 앱의 정책을 따릅니다.

5. 제3자 제공과 외부 서비스

현재 앱에는 개발자 서버, 광고·추적·분석 SDK, 계정 또는 결제 기능이 없습니다. 앱의 원본 오디오나 실제 대화를 개발자에게 전송하거나 판매하지 않습니다. OS 음성 모델 준비와 워치 전송 등 플랫폼 서비스는 Apple 또는 Google의 정책을 따릅니다.

대화 자막을 사용할 때는 대화 상대방에게 자막 사용 사실을 알려 주세요. 필요한 때만 마이크를 켜고 사용을 마치면 종료하세요.

6. 정보 삭제와 권한 관리

  • 생활 소리 기록: 앱의 기록 → 모든 기록 삭제에서 삭제합니다. 연결되지 않은 워치의 삭제는 다시 연결한 뒤 반영됩니다.
  • 자막·답변: 대화 종료·내용 지우기로 지웁니다.
  • 마이크·음성 인식·알림 권한: 휴대폰 또는 워치의 OS 앱 설정에서 변경할 수 있습니다.
  • 앱 삭제: 각 기기의 앱 삭제로 해당 앱의 로컬 데이터를 제거할 수 있습니다. 휴대폰과 워치에서 각각 삭제하세요.

OS 알림센터에 남는 알림은 시스템 설정에서 별도로 관리합니다. 회원가입이 없으므로 별도의 계정 삭제 절차는 없습니다.

7. 이메일 문의

사용자가 지원 이메일로 문의하면 발신 이메일 주소, 이름(포함한 경우), 문의 내용과 첨부 파일을 문의 확인·답변 및 문제 해결에 사용합니다. 앱이 자동으로 보내는 정보가 아닙니다. 목적을 달성해 더 이상 필요하지 않은 문의 정보는 삭제하며, 법령상 보관 의무가 있는 경우에는 해당 기간 동안만 보관합니다.

원본 대화 녹음이나 민감한 자막을 보내지 않아도 됩니다. 문의 정보의 열람·정정·삭제 또는 처리 중지를 원하면 아래 이메일로 연락해 주세요. 기기에만 있는 자막·기록은 운영자가 원격으로 조회할 수 없으므로 앱에서 직접 삭제할 수 있습니다.

8. 이 지원 웹사이트

이 페이지에는 별도의 분석 도구, 광고, 문의 입력 폼 또는 추적 스크립트를 넣지 않았습니다. GitHub Pages가 웹사이트를 호스팅하며, GitHub는 서비스 보안을 위해 방문자의 IP 주소를 기록할 수 있습니다. 자세한 내용은 GitHub Pages 안내와 GitHub 개인정보처리방침을 확인하세요.

9. 변경 및 문의

처리 방식이나 기능이 변경되면 이 페이지의 시행일과 내용을 갱신하고, 필요한 경우 앱 내 안내 및 동의 절차를 제공합니다. 광고·구매 기능은 현재 포함되지 않으며 향후 추가 시 관련 처리를 별도로 안내합니다.
